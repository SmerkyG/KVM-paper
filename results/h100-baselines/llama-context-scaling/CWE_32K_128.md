# 32K CWE held-out comparison

Llama-3.1-8B-Instruct, BF16, batch one on H100. We sampled 128 examples uniformly without replacement using seed 1042 from the same frozen RULER dataset revision. Both source rows and prompt hashes are disjoint from the original 32 CWE examples.

Both decoders use dense causal prefill. Squeezed fits the same initial Multipole index with 2,900 centroids per KV head and calibrates p90 on the same 100 routing queries. Greedy generation has a 120-token cap and scoring stops at the first EOS/EOT. The benchmark also replayed one original example separately. Both methods reproduced their prior first-response token IDs and Squeezed reproduced its p90 threshold.

| Decoder | Mean CWE score | Target-word hits |
|---|---:|---:|
| Dense BF16 | 43.67% | 559 / 1,280 |
| Squeezed p90 | 56.09% | 718 / 1,280 |

Squeezed changes the mean by **+12.42 percentage points** (95% paired bootstrap interval +7.19 to +17.89, 100,000 resamples of prompt pairs). Squeezed wins on 46 prompts, dense on 16, and 66 tie. Whole-word scoring gives 715 hits for Squeezed and 555 for dense. The original 32-example gap was +17.19 points. [Original comparison](DENSE_PREFILL.md#32k-ruler).
